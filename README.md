# 💫 About Me:
Desenvolvedor de sistemas com foco em **Front-end**, atuando em React, Vue.js e TypeScript na construção de sistemas web de gestão — e com vivência prática em **IoT/embarcados** (ESP32), integrando firmware a interfaces web via OTA.<br>
No **NUTES (Núcleo de Tecnologias Estratégicas em Saúde - UEPB)**, desenvolvo o SGF (Sistema de Gestão de Fluxos) e o design system "Ofício". Também projetei o firmware e o painel web de um sistema de controladora de acesso físico baseado em ESP32.<br>
Estudante de Bacharelado em Ciência da Computação pela Universidade Estadual da Paraíba (UEPB).

## 🚀 Projetos em Destaque:

**[Admin-blink-OTA](https://github.com/FranciscoKoder/Admin-blink-OTA)** — Gestor de Firmware (CriAtom Web OTA)
Painel React 19 + Vite + MUI para gravação remota de firmware (OTA) em controladoras de acesso ESP32, sem necessidade de IDE ou cabo. Upload via `XMLHttpRequest` com barra de progresso real, ping de rede automático, Basic Auth e tema dark técnico próprio.

**[OTA-Server-AP](https://github.com/FranciscoKoder/OTA-Server-AP)** — Firmware Base SCA (ESP32)
Firmware modular em C++ para controladora de acesso físico: provisionamento Wi-Fi via portal cativo, duplo sistema OTA (cabo/terminal/web), tarefas em background com FreeRTOS (buzzer/LED de status) e wipe remoto de memória NVS.
